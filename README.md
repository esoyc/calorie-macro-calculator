# 🥗 Kalori & Makro Hesaplayıcı

Kullanıcıların fiziksel özelliklerine, günlük hareket seviyelerine ve hedeflerine (Kilo Verme, Kilo Koruma, Kas Yapma) göre günlük alması gereken **Kalori**, **Protein**, **Karbonhidrat** ve **Yağ** miktarlarını otomatik olarak hesaplayan ve günlük besin tüketimini takip etmelerini sağlayan web uygulaması.

🚀 **Canlı Demo:** [calorie-macro-calcul-a6ae.bolt.host](https://calorie-macro-calcul-a6ae.bolt.host)

---

## 🛠️ Kullanılan Teknolojiler
* **Front-end:** React, TypeScript, Vite
* **Styling:** Tailwind CSS
* **Grafik & İkonlar:** Recharts, Lucide React

---

## ✨ Özellikler
* 📊 **BMR ve TDEE Hesaplama:** Mifflin-St Jeor formülü ile kişiye özel kalori ihtiyacı belirleme.
* 🥩 **Makro Besin Dağılımı:** Hedefe özel gram bazında Protein, Karbonhidrat ve Yağ hedefleri.
* 🍲 **Öğün Takibi:** Günlük tüketilen yemekleri ekleme ve kalan kalori/makro miktarını anlık grafiklerle izleme.
* 💾 **Yerel Veri Saklama:** Kullanıcı verilerini tarayıcı hafızasında saklayarak oturumlar arası veri koruması.
